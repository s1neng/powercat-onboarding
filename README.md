# 파워캣 온보딩 v3

명세: [`기획서.md`](기획서.md)

## 실행

설치가 필요 없는 정적 웹입니다 (Windows 기준).

- **권장**: `실행.bat` 더블클릭 → 로컬 서버가 뜨고 브라우저가 열립니다. 종료는 검은 창을 닫으면 됩니다.
- **바로 보기**: `index.html` 더블클릭 (단, 이 방식에서는 수료증 PNG에 파워캣 도장이 빠집니다)

수정은 메모장·VS Code 등으로 파일을 고친 뒤 브라우저를 새로고침하면 바로 반영됩니다.

브라우저에서 `http://localhost:8770/` · 로직 테스트는 `http://localhost:8770/tests.html`

## 지역 실데이터 수집 (충북본부)

한전 전력데이터개방포털 「계약종별 전력사용량」 API로 충북 시군구별 **판매수입(전기요금 합계)·고객호수·전력사용량**을 최근 12개월 받아 옵니다.

1. [전력데이터개방포털](https://bigdata.kepco.co.kr)에 가입하고 API 인증키(40자리)를 발급받습니다.
2. `데이터수집.bat` 더블클릭 → 처음 한 번 키를 붙여넣으라고 물어봅니다.
   - 키는 `%APPDATA%\powercat-onboarding\kepco-key.txt`(프로젝트 폴더 밖)에 저장되어 zip으로 공유되지 않습니다.
3. 완료되면 `js/region-data.js`가 만들어지고, 사용자 본부가 **충북본부**일 때 지역 화면이 실데이터로 바뀝니다. 다른 본부는 샘플을 보여 줍니다.
4. 매월 한 번 다시 실행하면 갱신됩니다. (공개 자료는 보통 1~2개월 늦게 올라옵니다)

키 없이 화면만 시험하려면 PowerShell에서 `collector\collect.ps1 -Mock` (모의 데이터, 배지에 "모의 데이터"로 표시). 다른 시도는 `-MetroName 경기도 -Hq 경기본부` 처럼 바꿀 수 있습니다.

## 맛집·관광지 이름 검색 (카카오 로컬)

'우리 지역 알려주기' 등록 팝업에서 이름을 검색하면 결과 목록이 나오고, 하나를 고르면 이름·주소·시군·지도 핀이 자동으로 채워집니다.

1. [카카오 개발자센터](https://developers.kakao.com) → 내 애플리케이션 → 애플리케이션 추가 → 앱 키의 **REST API 키**를 복사합니다. (무료, 카드 등록 없음)
   - 검색할 때 403 오류가 나면: 내 애플리케이션 → 제품 설정 → **카카오맵** → 사용 설정 ON
2. `카카오키설정.bat` 더블클릭 → 키를 붙여넣습니다. 키가 맞는지 바로 확인한 뒤 `%APPDATA%\powercat-onboarding\kakao-key.txt`에 저장합니다(zip에 포함되지 않음).
3. `실행.bat`으로 앱을 켭니다(이미 켜져 있으면 창을 닫고 다시). 키가 브라우저에 노출되지 않도록 로컬 서버(`serve.ps1`)가 `/api/place-search`로 대신 호출합니다.

키가 없거나 `index.html`을 직접 열면 OpenStreetMap 이름 검색으로 대신합니다. 큰 관광지는 찾지만 작은 식당은 거의 없으니, 그때는 주소를 직접 입력하세요. 팀원마다 각자 키를 받아 설정하면 됩니다.
> 네이버 검색 API는 2026년 7월부터 NAVER API HUB(네이버클라우드)로 옮겨져 신규 발급이 어렵고 유료 전환이 예고돼 카카오를 사용합니다.

## 화면

| 경로 | 화면 |
|---|---|
| (처음 접속) | 정보입력 — 파워캣이 3D로 등장해 사번·이름·직무·본부·입사일 질문 |
| `#/home` | 메인 — D-day, 목표 이수율(업무40·교육40·지역20), 동기 목록(대화명·응원), 카테고리 버튼 |
| `#/work` | 업무 — 캘린더(주·월·연, 직접추가, AI 추천, 메일·쪽지 반영), 인수인계, 업무검증, 담당자 추천, 메일·공문 초안 |
| `#/edu` | 교육 — 이수 시간 기준 이수율, 필수교육 목록, 마감 7일 전 팀장 알림, 교육 일정 |
| `#/region` | 지역 — 본부 사업소 판매수입·고객호수·전력사용량, 맛집·관광지·지역특성 등록 |
| `#/graduate` | 졸업 — 전체 100% 시 수료증(PNG)·선물 신청 |
| `#/admin` | 관리자 (임시 PIN `0000`) — 개인별 온보딩 기간, 현황, 알림·선물 내역, 팀장 메일 |

## 구조

```text
js/config.js     운영 설정 (기간·가중치·사번 규칙·관리자 PIN·사내 AI 주소)
js/data.js       샘플 데이터 (직무·본부·교육·규정·담당자·동기)
js/region-data.js 지역 실데이터 (collector/collect.ps1 이 생성, 비어 있으면 샘플)
collector/       한전 개방포털 API 수집 스크립트
js/core.js       날짜·저장소·이수율·일정 추출 (순수 함수)
js/ai.js         AI 기능 (AI_ENDPOINT 미설정 시 브라우저 내 시연 응답)
js/app.js        라우팅·공통 UI
js/views/*.js    화면별 렌더링
tests.html       로직 테스트 (브라우저에서 열기)
```

## 운영 전환 시

1. `config.js`의 `AI_ENDPOINT`에 사내 AI 게이트웨이 주소 → OCR·초안·검증이 사내 모델로 전환
2. `data.js` 샘플을 인사·교육·영업 시스템 API로 교체 (명세 10장 미결 사항 참고)
3. localStorage → 서버 DB, 임시 로그인·PIN → SSO 역할 권한
4. 팀장 알림 `mailto` → 사내 메일 발송 API
